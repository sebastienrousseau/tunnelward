# Release notes

One file per release, `vX.Y.Z.md`, holding only the hand-written
`## Highlights ⭐️` section: two to four bullets, `* **Headline**: one or
two plain sentences.`, no em dashes. The release workflow adds What's
Changed, the checksums and the Full Changelog link
(`scripts/release-notes.sh`), and reads these files from `main`, so a
release can be rebuilt later with corrected notes.
