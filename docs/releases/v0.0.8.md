## Highlights ⭐️

* **Try it in one command**: `tunnelward dev --to http://127.0.0.1:8080` puts a gateway and a connector in front of a local service, over the same post-quantum mutual TLS as a real deployment, with throwaway certificates made at startup.
* **On crates.io**: `cargo install tunnelward`, and the `tunnelward-proto`, `-crypto`, `-connector` and `-gateway` crates to embed, documented on docs.rs.
* **An admin API**: health, readiness, an inventory that shows only counts unless asked for detail, Prometheus metrics and drain, behind a bearer token or loopback only.
* **Run and check a gateway from a file**: `tunnelward gateway --config`, `tunnelward config check` and `tunnelward doctor`, and every error now has a stable id explained in `docs/errors.md`.
