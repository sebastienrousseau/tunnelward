## Highlights ⭐️

* **A scripted bulk export is refused mid-run**: with `[risk]`, every request gets a score from how fast a client, a tool and an IP prefix are calling, and from steps between tools the client has never taken. A policy rule with `risk = 70` refuses the run once it crosses, before the calls reach your server.
* **Canaries end the session**: a call to a tool no real agent uses, or a request carrying a planted record, is refused, and the client and its MCP session stay locked out for an hour (`TW-I013`). Every alert goes to observers, the audit log and the trace.
* **Traces and RED metrics without the OpenTelemetry SDK**: each request is a span sent to your collector as OTLP/HTTP JSON, continuing the client's trace, with route, tools, identities, TLS group and risk. `/metrics` has rate, errors and duration per route, with exemplars, and `deploy/grafana/tunnelward.json` charts them.
* **Attestation limits are configurable**: `max_signatures`, `future_skew_secs` and `max_revoked` in `[attestation]`, fixed constants in 0.0.15.
