## Highlights ⭐️

* **Post-quantum TLS by default**: `tw-crypto` builds rustls configurations on AWS-LC that speak TLS 1.3 only and offer the hybrid group `X25519MLKEM768` first, with an opt-in hybrid-only mode that refuses classical key exchange.
* **Mutual TLS for connectors**: the connector listener requires a client certificate from configured roots; the agent ingress asks for none.
* **Handshakes under test**: tests assert the negotiated group, the X25519 fallback, the hybrid-only refusal, and mutual-TLS acceptance and rejection.
* **Releases publish, and are signed**: packaging no longer stops on the `LICENSES/` directory, which had blocked the first release run, and `SHA256SUMS` now ships with a keyless cosign signature.
