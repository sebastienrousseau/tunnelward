## Highlights ⭐️

* **The workspace exists**: one crate per concern (protocol, crypto, identity, attestation, policy, MCP, audit, gateway, connector), each a placeholder for now, plus a `tunnelward` binary that reports its version.
* **One gate for everything**: `cargo xtask ci` runs formatting, clippy, tests, docs, cargo-deny, cargo-vet, REUSE and the complexity ceilings, and CI runs exactly that command.
* **Rust 1.89 and up**: the minimum supported version matches kyberlib, the crate Tunnelward will use for ML-KEM.
