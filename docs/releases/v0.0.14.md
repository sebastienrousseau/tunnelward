## Highlights ⭐️

* **Every call is recorded in a log that shows tampering**: with `[audit]`, each request and admin action goes to a hash-chained JSON Lines file, signed every 1,000 lines or 60 seconds with a composite ML-DSA-65 + Ed25519 key. `tunnelward audit verify` checks it offline and names the first line that was changed, removed or reordered.
* **No raw personal data by default**: client addresses and certificates are written as keyed-hash pseudonyms, and tool arguments, request and response bodies as SHA-256 digests; the query string is never logged. Raw addresses are kept only if you ask, beside the log, for at most 30 days.
* **Callers can get a signed receipt**: with `receipts = true`, every answer carries `tw-receipt`, which `tunnelward receipt verify` checks offline; changing any field breaks it. Signing one takes 90 to 100 µs, so it is off by default.
* **The log speaks OCSF**: `tunnelward audit export` writes each entry as an OCSF 1.3.0 event for a SIEM. Anchoring checkpoints to an RFC 3161 timestamp authority moves to a later version (ADR 0008).
