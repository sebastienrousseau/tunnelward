## Highlights ⭐️

* **A working tunnel**: the connector dials the gateway over TLS (ALPN `tw/1`), registers, and then serves HTTP/2 on the same connection with the roles reversed, so the service behind it needs no inbound port.
* **Routing by domain and path**: requests go to the connector for the exact domain or a `*.` wildcard, then the longest matching route on a `/` boundary, then the catch-all `*`. A connector leaves the table when its connection ends.
* **Strict admission**: the gateway closes a connection that does not negotiate `tw/1`, answers a bad register frame with a `Reject` code, refuses an oversized frame before reading it, and drops a connector that never registers.
