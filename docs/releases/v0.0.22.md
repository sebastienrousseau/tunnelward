## Highlights ⭐️

* **The gateway can route a call it cannot read**: in gateway-blind mode (experimental) an agent seals a tool call's arguments to the connector's key. The gateway still routes, applies policy and rate limits, and audits by tool name, but the arguments and the answer cross it sealed, and renaming the tool makes the call fail to open.
* **Hybrid post-quantum end to end**: sealing is HPKE (RFC 9180) with X-Wing (ML-KEM-768 and X25519), written here over aws-lc-rs with no new runtime dependency, and checked against RFC 9180's test vectors and the X-Wing draft's known answers.
* **Agents in TypeScript and Java**: helpers on standard libraries only (Node 24.7 or later and JDK 25; browsers through kyberlib-wasm) interoperate with the Rust connector in both directions. Connectors turn it on with `[blind]` and make their key with `tunnelward blind keygen`.
