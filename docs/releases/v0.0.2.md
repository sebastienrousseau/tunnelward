## Highlights ⭐️

* **The wire protocol**: `tw-proto` defines the Register, Accept and Reject frames a connector and gateway exchange, with stable reject codes and the hard limits from the specification.
* **Length checked before reading**: a frame is a 4-byte length and one CBOR value, and the length is refused before any of the body is read, so a peer cannot make the gateway buffer more than 64 KiB.
* **Tested hard**: property tests, Miri, and a fuzz target that ran 30 minutes (about 250 million inputs) with no crash.
* **Release tooling**: signed tags now produce binaries for five platforms, checksums, an SBOM, provenance, a container image and a Homebrew formula.
