## Highlights ⭐️

* **Audit events reach your SIEM as they happen**: `[audit.export]` sends each audit entry as an OCSF event over syslog (RFC 5424, over TLS) and as OpenTelemetry logs. The log file stays the record, and a slow SIEM never holds up a request.
* **A person approves each high-impact call**: with `[approval]`, a call to a `high_impact` tool gets MCP's URL elicitation; the agent's user signs in at their identity provider and approves exactly that call, which then runs once. A changed argument needs its own approval.
* **Evidence for a post-quantum inventory**: `tunnelward crypto report` lists the TLS version, key exchange, cipher suite and key of every connector connection, and counts the hybrid ones.
* **A DPIA template and no new dependencies**: `docs/DPIA.md` states what each feature records. Syslog, OTLP logs and the OIDC sign-in are written here; the Kubernetes operator moves to 0.0.21.
